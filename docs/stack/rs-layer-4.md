# 第 4 层：样本与特征

训练样本不是现成的：曝光时的特征和之后才到的用户行为要按 request ID 拼起来，标签可能晚几分钟（点击）到几天（转化）；负样本太多要下采样，召回要从全库里采负样本，采完还要把概率校正回去；特征要和线上打分时用的那一份完全一致。这一层的取舍是新鲜度对完整性：等得越久标签越全，但样本越旧、缓存越大。

- **样本拼接 / 延迟标签**：拼接窗口、fake negative。
- **feature store / 一致性**：服务时记特征，point-in-time join。
- **负采样**：下采样校正、in-batch 负样本的 logQ 修正。
- **流式管线**：Kafka + Flink 拼样本，在线和批训练共用。
