# 第 2 层：记忆与检索

上下文窗口放不下的知识和历史，要在需要时取回来。这一层管离线把文档切块、算 embedding、建索引，在线做混合检索、rerank、把 top-k 拼进 prompt；还有 agent 自己的长期记忆怎么写、怎么查、什么时候忘。核心权衡是召回对延迟和 token：多取几块召回更高，但每块都要进窗口付钱；rerank 更准，但每个候选都要过一次模型。

- **RAG 管线**：切块、embedding、索引、检索、拼 prompt，每一步的延迟和成本。
- **向量检索 / rerank**：dense 和 BM25 两路召回，再用 cross-encoder 精排。
- **长期记忆**：跨会话的写入、检索、遗忘。
