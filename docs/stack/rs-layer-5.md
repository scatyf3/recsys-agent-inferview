# 第 5 层：模型更新

搜推的数据分布一直在变，模型训完就开始变旧，所以训练不停：在线消费实时样本、按分钟把变了的参数推到线上。这一层管模型多新鲜、怎么安全地上线：增量同步只推被碰过的行，快照和增量组合起来能恢复到任意时刻，上线前看离线指标和 A/B，出事能回滚。核心权衡是新鲜度对稳定性：推得越勤效果越好，坏模型扩散得也越快。

- **在线 / 增量训练**：批训练打底，在线训练追新。
- **checkpoint 与增量导出**：全量快照加增量，快照可以很稀。
- **参数同步到线上**：稀疏分钟级、dense 天级。
- **指标 / A/B / 回滚**：AUC、GAUC、NE，推送前检查。
