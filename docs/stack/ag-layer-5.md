# 第 5 层：编排

一个任务从提问到交付，中间是几十轮「调模型 → 调工具」的循环，可能还会派出 sub-agent 并行干活。这一层管 loop 怎么推进、什么时候停、多个 agent 怎么分工，以及任务跑到一半进程挂了怎么从断点续上。权衡是并行度对 token 成本：多 agent 更快、覆盖更广，但 token 成倍增加。

- **agent loop**：调模型、执行工具、追加结果，直到最终答案或预算用完。
- **多 agent**：fan-out 给 sub-agent，只回传结论。
- **持久执行**：事件历史或 checkpoint，重启后重放、跳过已完成的步骤；有副作用的步骤要幂等。
