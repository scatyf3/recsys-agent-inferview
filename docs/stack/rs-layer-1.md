# 第 1 层：Embedding 存储

模型参数的 99% 以上在 embedding 表里，这一层管这些稀疏参数怎么存：ID 怎么映射到行（哈希还是动态表）、哪些 ID 值得占一行（准入）、什么时候删（淘汰）、每行能压多小（量化、混合维度）、热的行怎么留在快的存储里（缓存）。核心权衡是内存对效果：行越多、精度越高，效果越好，但每多一个 ID 就多几百字节。

- **embedding 表与哈希**：固定大小加哈希会冲突，冲突比例约 N/(2m)。
- **动态 embedding**：一个 ID 一行，靠准入和过期控制总量。
- **多级缓存**：HBM 当 DRAM 的缓存，命中率决定有效带宽。
- **压缩**：fp16 / int8、rowwise 优化器、混合维度、QR 分解。
