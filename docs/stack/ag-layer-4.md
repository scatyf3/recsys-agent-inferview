# 第 4 层：执行环境

Agent 写的代码、敲的命令不能直接在宿主机上跑，要放进隔离的沙箱。这一层管隔离用什么（容器、gVisor、microVM），沙箱怎么快速起来（预热池、快照恢复），以及沙箱里的代码能碰到什么（文件、网络、密钥）。权衡是隔离强度对启动延迟和密度：隔离越强，每个沙箱的开销越大。

- **隔离**：共享内核的容器、用户态内核 gVisor、独立内核的 microVM。
- **冷启动**：预热池按到达率和补货时间定大小，快照把启动压到百毫秒级。
- **安全**：沙箱挡代码逃逸，挡不住 prompt injection，还要最小权限和出口控制。
