# 第 3 层：工具

模型本身只会输出 token，调外部能力要靠一套约定：工具的 schema 怎么描述给模型，模型用什么格式发出调用，服务端怎么解析，结果怎么回填。这一层管调用格式、协议（MCP）和调度（一次发几个、能不能并行）。核心权衡是工具数量对上下文：工具越多能力越全，但每个工具的定义都要占输入 token、每轮都要付钱，工具多了模型还更容易选错。

- **function calling**：JSON / XML / 特殊 token 格式，解析与约束解码，解析失败的恢复。
- **MCP / 工具协议**：host、client、server 三方，stdio 与 Streamable HTTP 两种传输。
- **并行工具调用**：一轮发出多个互不依赖的调用，等待时间从求和变成取最大值。
