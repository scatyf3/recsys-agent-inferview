# 第 0 层：硬件与存储

搜推训练的硬件约束和 LLM 不一样：算力往往用不满，卡住的是容量和带宽。embedding 表从几十 GB 到几十 TB，要在 HBM、DRAM、SSD 之间分层放；查表是随机读、几乎不做计算，吃的是内存带宽；表分到多张卡上以后，每步两次 all-to-all 吃的是网络带宽；样本从分布式存储流进来、在 CPU 上解析和哈希，吃的是主机侧的 CPU 和网络。这一层的取舍是容量对带宽：放得越靠下越便宜、越大，读得越慢。

- **HBM / DRAM / SSD**：放不进 HBM 的表靠缓存命中率撑住带宽。
- **网络**：节点内 NVLink 比跨节点网卡快一个数量级，决定表怎么切。
- **CPU**：特征处理、PS 的 key-value 存储都在 CPU 侧。
